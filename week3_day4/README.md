# Week 3 Day 4 — Looker Studio Dashboard

## Objective

Build an interactive business dashboard using Google Looker Studio connected to a Google Sheets dataset.

## Data Source

The dashboard uses the `looker_studio_week3_day4.csv` dataset.

The dataset contains:

* Date
* Region
* Product
* Revenue
* Units Sold
* Profit

## Dashboard Components

The dashboard includes five chart types:

1. **Scorecard** — Total Revenue
2. **Bar Chart** — Revenue by Region
3. **Line Chart** — Revenue Trend Over Time
4. **Pie Chart** — Revenue by Product
5. **Table** — Detailed business data

## Interactive Controls

* Date Range Control
* Region Filter
* Product Filter

## Dashboard Theme

A clean professional theme using Cynaris branding and consistent formatting.

## Business Analysis

The dashboard helps analyse:

* Total revenue and profit
* Revenue by region
* Revenue trends over time
* Product performance
* Units sold
* Business performance using interactive filters

## AI Task

CIA was used to review best practices for designing a Looker Studio dashboard for a client presentation.

### Key Insights

* Keep the dashboard simple and easy to understand.
* Place important KPIs at the top.
* Use suitable chart types for each analysis.
* Use consistent colours and fonts.
* Add filters for interactive analysis.
* Use clear chart titles and labels.
* Avoid unnecessary visual elements.
* Focus on useful business insights.
